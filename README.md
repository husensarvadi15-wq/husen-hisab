# HUSEN HISAB - Complete Android Studio Project

## Architecture & Features
- **UI Framework**: Modern Jetpack Compose with Dark Mode (Pure Black & Gold Yellow).
- **Architecture**: MVVM with Kotlin Coroutines & StateFlow.
- **Backend & Auth**: Firebase Phone OTP Authentication + Firebase Cloud Firestore.
- **Accurate Arithmetic**: Precision `BigDecimal` calculations ensuring zero rounding leak.
- **Independent Ledgers**: Two strictly separated ledgers (નાના પોલ & મોટા પોલ).
- **Reports**: Daily/Monthly aggregates with instant CSV / Excel sharing.

## How to Build the APK in Android Studio
1. Extract `HusenHisab_Complete_Project.zip`.
2. Open **Android Studio** -> Select **File > Open** -> Choose the extracted `HusenHisab` folder.
3. Allow Gradle Sync to finish automatically (JDK 17+ recommended).
4. Go to **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
5. Once build completes, click **Locate** to get your `app-debug.apk` and install it on your mobile!
